# 🎓 Telegram-бот: Тренажер Национального сертификата по русскому языку и литературе с ИИ Gemini

Умный Telegram-бот с искусственным интеллектом **Google Gemini**, разработанный специально для подготовки к сдаче экзамена на **Национальный сертификат по русскому языку и литературе** (уровни B+, A, A+).

---

## ⚡ Особенности и возможности

1. **Модель Gemini без зависаний с огромными лимитами:**
   - По умолчанию используется **`gemini-2.0-flash`** — новейшая сверхбыстрая модель от Google, которая генерирует ответы за 1–2 секунды и не зависает.
   - Автоматический **Fallback (резерв)** на **`gemini-1.5-flash`** при любых сетевых задержках или сбоях.
   - Огромные бесплатные лимиты (до 15 RPM, 1 500 запросов в день и окно контекста в миллион токенов).

2. **📑 Генерация экзаменационных тестов в Word (.docx) (50 + 10):**
   * Создание полноценного экзаменационного сборника:
     - **50 тестовых вопросов** с 4 вариантами ответа (A, B, C, D).
     - **10 открытых письменных заданий** с модельными ответами и критериями оценивания.
     - **Итоговая таблица ключей (1–50)** для быстрой проверки.
   * **Подача материала:** можно просто ввести тему текстом ИЛИ отправить боту файл (**PDF, Word .docx, TXT**), и ИИ сгенерирует тест на основе содержимого файла!
   * Готовый файл в красивом дизайне и шрифтах отправляется документом Microsoft Word (.docx).

3. **Полное соответствие спецификации Национального сертификата:**
   - ✍️ **Русский язык:** Орфография, Пунктуация, Морфология, Синтаксис и культура речи, Лексика и фразеология, Комплексный анализ текстов.
   - 📖 **Литература:** Классика XIX века (Пушкин, Толстой, Достоевский и др.), Литература XX века, Теория литературы, жанры и тропы, анализ стихов и цитат.
   - Формат строго соответствует стандарту: 4 варианта ответа (A, B, C, D) с одним правильным.

3. **Интерактивное тестирование и ИИ-разборы:**
   - Мгновенная проверка нажатием кнопки (A, B, C, D).
   - Подробное объяснение правил к каждому вопросу сразу после ответа.
   - Кнопка **«💡 Глубокий разбор от ИИ»** для получения методической подсказки, разбора ловушек и формулировки правил.
   - **🎯 Экспресс-тест (5 вопросов)** для комплексной тренировки.

4. **ИИ-репетитор по любым вопросам пользователя:**
   - Любое сообщение с вопросом, правилом или заданием из сборника тестов мгновенно анализируется ИИ.
   - Пошаговое решение сложных заданий с пояснением логики.

5. **📊 Статистика:**
   - Подсчет решенных заданий, правильных ответов и процента успешности по каждому предмету.

## 🛠️ Установка и запуск

### 1. Предварительные требования
У вас уже установлен Python 3.11+.

### 2. Настройка ключей в `.env`
Откройте файл `.env` в корне проекта и укажите ваши ключи:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
GEMINI_API_KEY=ваш_ключ_google_gemini
GEMINI_MODEL=gemini-2.0-flash
GEMINI_FALLBACK_MODEL=gemini-1.5-flash
```

#### Где взять ключи:
- **`TELEGRAM_BOT_TOKEN`**:
  1. Откройте Telegram и найдите официального бота **[@BotFather](https://t.me/BotFather)**.
  2. Отправьте команду `/newbot` и следуйте инструкциям.
  3. Скопируйте полученный API токен (вида `123456789:ABCDefgh...`) и вставьте в `.env`.

- **`GEMINI_API_KEY`**:
  1. Перейдите на сайт **[Google AI Studio](https://aistudio.google.com/)**.
  2. Войдите через Google-аккаунт.
  3. Нажмите кнопку **«Get API key»** -> **«Create API key»**.
  4. Скопируйте ключ и вставьте в `.env`.

### 3. Запуск бота
Выполните в терминале (командной строке):

```bash
python bot.py
```

После запуска в терминале появится сообщение:
`🚀 Бот успешно инициализирован. Запуск long-polling...`

Теперь откройте вашего бота в Telegram и отправьте команду `/start`!

## 📁 Структура проекта

- `bot.py` — главный файл запуска Telegram-бота.
- `config.py` — конфигурация, системные промпты и загрузка переменных окружения.
- `gemini_service.py` — сервис для работы с Google Gemini API (генерация вопросов, разбор, чат с репетитором).
- `keyboards.py` — интерактивные кнопки меню и вариантов ответов.
- `storage.py` — хранилище сессий пользователей и статистики.
- `handlers/`
  - `start.py` — команды `/start`, `/help`, статистика и справка о сертификате.
  - `test_runner.py` — прохождение тестов, проверка ответов и глубокий разбор от ИИ.
  - `ai_chat.py` — обработка любого вопроса пользователя репетитором ИИ.
- `.env` — файл с вашими секретными ключами.
- `requirements.txt` — зависимости Python.
